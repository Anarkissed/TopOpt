DIAGNOSIS — stale expectation, NOT a mapping regression
-------------------------------------------------------
octet_relative_density(cell, r) is pure geometry: it voxelizes one octet unit cell
on the library basis (vpc48) and returns the solid fraction. It NEVER reads kOctet,
so a given r/L maps to exactly the same rho before and after the band change. Only
the band edges (lattice_rho_min/max) moved. Mapped rho for the ORIGINAL radii:

  case                  r/L     rho        OLD[0.14764,0.59093]   NEW[0.05047,0.89988]
  thin  (5.0, 0.30)     0.060   0.095052   BELOW                  INSIDE   <- fails "< lo"
  fat   (5.0, 1.05)     0.210   0.667390   ABOVE                  INSIDE   <- fails "> hi"
  mid   (5.0, 0.75)     0.150   0.409578   INSIDE                 INSIDE   (still ok)

The thin strut (0.0951) used to sit below the old floor 0.148 and now sits above the
new floor 0.050; the fat strut (0.6674) used to sit above the old ceiling 0.591 and
now sits below the new ceiling 0.900. The map is unchanged and correct — the test's
radii were chosen against the old band and became stale when PR 237 widened it.
2c (refusal) still passes because it feeds explicit out-of-band rho values, not radii.
