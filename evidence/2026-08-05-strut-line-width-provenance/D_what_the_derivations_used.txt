THE ANSWER: every derivation on that run used 0.45 mm as the OUTER width. The
0.42 mm he set never reached MinimizePlasticOptions, so the mirror sentinel was
still in place and the outer width WAS the inner width, 0.45 mm.

WHAT THAT CHANGED, EXACTLY:
  wall_thickness_mm (the solid perimeter ring the width-aware gate would size)
    used   : 5 x 0.45 = 2.25 mm      <- what run_info.json records, at
                                        outer 0.45 mm / inner 0.45 mm
    honest : 0.42 + 4 x 0.45 = 2.22 mm  at outer 0.42 mm / inner 0.45 mm
    honest - used = -0.03 mm (-1.33% of 2.25 mm). The ring the run used is
    THICKER than the beads he actually prints, because the true outer bead
    (0.42 mm) is narrower than an inner one (0.45 mm).
