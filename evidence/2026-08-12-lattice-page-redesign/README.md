## Reproduce

    # core
    cmake -S core -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --target topopt_cli test_lattice_depth_tie
    ./build/test_lattice_depth_tie

    # the three arms (each walks the production 4-rung ladder at resolution 128)
    E=evidence/2026-08-12-lattice-page-redesign/s0_depth
    for arm in mismatch matched auto; do
      $E/topopt-cli.snapshot run $E/job_$arm.json --out $E/out_$arm --no-iteration-csv
    done

    # app
    swift test --package-path app/TopOptKit --filter "LatticeBarrierModelTests|LatticeWizardTests"

## Two things the arms had to be told, by core

1. **`"skin": "rim"` emits nothing on this part**, and core refuses rather than
   export an undressed lattice under a finish the job asked for. A pre-existing
   gap (handoff 2026-08-05-lattice-cell-size-adaptation §7), not this task's — all
   three arms carry `"skin": "none"`, which is what core itself instructs.
2. **A custom `ladder` is not allowed alongside `loads`** — in loadcase mode the
   production ladder and margin apply. So every arm walks the full 4-rung ladder;
   there is no short version of this measurement.
