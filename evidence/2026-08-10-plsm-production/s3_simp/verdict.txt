★ THE FIRST DIAGNOSIS IN THIS FILE WAS WRONG. THE CORRECTION IS BELOW.

It read: the arms follow the same trajectory and merely stop at different
iterations, so the margin gap is a termination artefact. The per-iteration
data refutes it. Compliance compared at MATCHED iterations:

                          rung 0        rung 3
  iteration 1             0.00e+00      1.45e-03  (inherited from rung 2)
  iteration 2             5.69e-05      1.34e-03
  worst, mid-run          3.16e-04      8.60e-02
  last matched iteration  3.67e-04      9.54e-05

The trajectories diverge by up to 8.6% in compliance. That is a DIFFERENT
OPTIMISATION, not a perturbation at the noise floor.

The mechanism should have been predicted. The sensitivity field is computed
from the displacement field; loosening the solve from 1e-8 to 1e-3 admits a
displacement wrong by ~1e-3, so the design update is wrong by ~1e-3 and the
next iteration starts somewhere else. Rung 0 iteration 1 is bit-identical
because both arms start from the same uniform design; from iteration 2 they
are on different paths.

SO THE HONEST STATEMENT IS: loose+warm does not reproduce the shipped design.
It converges to a DIFFERENT design that is JUST AS GOOD — margins within
0.09%, every verdict unchanged. That is a defensible property of a
well-conditioned problem. It is NOT "the same design to seven significant
figures", and this task must not repeat that claim for the ladder.

★ AND THE ATTRIBUTION IS UNRESOLVED. The failing arm combines TWO changes:
the loosened tolerance (the `draft` block, WHICH ALREADY SHIPS and is not part
of this task) and the matrix-free warm start (the only thing this task added).
The mechanism above points at the tolerance: a warm-started solve converges to
the SAME tolerance and so cannot move the sensitivity field by more than that
tolerance. If that is right, the blocked-stop belongs to a feature that already
exists and this task's change is exact and free. The `loose`-alone arm — one
35-minute run — decides it, and was cut when four arms did not fit.
