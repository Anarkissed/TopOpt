# evidence — 2026-08-10-plsm-production

Everything here is regenerated by `./reproduce.sh`. Nothing is cloned and nothing
is downloaded; every input is already in this repository.

★ **SET `SCRATCH` FIRST**, to a directory OUTSIDE the repository. The fields
these runs write are large (a 468,224-voxel float64 field is 3.75 MB and there
are dozens), and R9 forbids scratch at the repository root. What is committed
here is the MEASUREMENTS — the `.txt` verdicts, the `.csv` tables, the per-run
`iterations.csv` and `report.json` — not the fields.

★ **THREE THREADS THROUGHOUT** (`--threads 3`, a flag this task added). Every
wall clock compared against another was measured with nothing else running. The
measurements that are NOT wall clocks — every roughness, every margin, every
solver-step count — are deterministic and unaffected by what else was on the
machine.

| script | what it measures | rough cost, 10 cores / 3 threads |
|---|---|---|
| `run_s0_core_move.sh` | the three header moves into core are no-ops | ~10 min |
| `run_s3_simp.sh` | S3(b): the solver win on SIMP, four arms, four rungs | ~100 min |
| `run_s2_frontier.sh` | S2: the knot-lattice frontier at rung 0.68 | ~60 min |
| `run_s4_lattice.sh` | S4: a parametric design, latticed, against SIMP's | ~25 min |
| `run_r1_byte_identity.sh` | R1: SIMP's default path, byte for byte | ~20 min |
| `assertion_census.sh` | R8: no assertion or refusal disappeared | seconds |

`s3_table.py`, `s2_table.py` and `s4_table.py` read the runs' own artefacts and
compute sums and ratios. They retype nothing.

and against nothing else.

## the one thing to read first

`../..//docs/handoffs/2026-08-10-plsm-production.md` §1. PR 324's probes and the
shipped ladder target **different volumes at the same nominal rung** — 75,281
against 88,424 printed voxels at rung 0.68 — so its "15% lighter" is a convention
difference and not a result. The production path uses the ladder's convention, so
