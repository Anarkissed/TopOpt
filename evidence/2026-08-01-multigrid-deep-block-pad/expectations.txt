after a design flaw was found in the gate). Reading the builder showed that
build_hierarchy / build_mf_hierarchy accept on ACTUAL active-DOF counts at
the walk stop, not on the conservative full-node bound mg_grid_coarsenable
uses — so an all-even bound-rejected grid with a SPARSE active set (a thin
part in a design-box expanse: exactly 125's occ<=0.5 rows) can already build
today. The gate was refined to count actual actives at the stop depth
(mg_unpadded_stop_active) and pad only when that count exceeds the cap.
